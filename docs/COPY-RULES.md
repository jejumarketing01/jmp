# 문구 점검 규칙

목표: 사이트에 들어온 사장님(주로 음식점)이 한 번 읽고 바로 이해한다. 사실은 [카피_기준자료.md](카피_기준자료.md)만 근거로 쓴다.

## 점검 질문

모든 문구가 아래를 통과해야 한다.

- 사장님이 카톡 문의에 그대로 쓸 수 있는 말인가?
- 한 가지로만 읽히는가? (비유·말장난·뒤집는 말 없이 긍정문으로)
- 누가, 무엇을 하는지 드러나는가?
- 한 문장에 하나만 담았는가?
- 빼도 뜻이 통하는 단어를 뺐는가?
- 사실과 같은가?

## 길이

| 요소 | 기준 |
|---|---|
| H1 | 20자 안팎. 길면 두 줄 |
| 섹션 제목 | 15자 이내. 표준 표현 우선 ("주요 서비스", "자주 묻는 질문", "오시는 길", "상담 신청") |
| 카드 제목 | 10자 안팎 |
| 본문 한 문장 | 40자 이내 |
| 버튼 | 2~10자 |

## 말

| 쓴다 | 대신 쓰지 않는 말 |
|---|---|
| 가게 | 업장 (매장은 본문 일부만) |
| 홍보, 광고 | 마케팅 활동, 브랜딩 |
| 장사가 안 된다 | 매출 부진 |
| 손님 | 고객 유입, 트래픽 |
| 관리 | 운영 대행 |
| 한 달 | 30일 |
| 광고 결과 | 성과 지표, ROI |
| 사장님 | 고객님, 여러분 |
| 홍보 영상, 릴스 | (숏폼은 가격표 같은 정확한 이름이 필요할 때만) |

허용하는 업계 말: 플레이스, 릴스, 파워링크, 인스타, 유튜브.

## 말투

- 기본 "~합니다 / ~드립니다", 묻는 카드는 "~나요?", 계약 조항은 명사형("위약금 없음"), 인칭은 "저희".

## 사실 지키기

- 순위·매출을 약속하는 말 대신 사실을 쓴다: "플레이스 순위는 네이버가 정해서, 보장하지 않습니다."
- 하는 일은 "이유를 찾아드립니다 / 업체를 연결해 드립니다". 직접 고치거나 시공하는 것처럼 쓰지 않는다.
- 하지 않는 일(블로그 대행, 홈페이지 제작, 제주 밖 촬영, 리뷰 작업)은 하는 것처럼 보이지 않게 한다.
- 매출 밀착 관리·컨설팅·브랜딩은 금액 대신 "상담 때 안내드립니다". 성과 연동 보수는 쓰지 않는다.
- 성공사례 7~12번은 업종 + 지역만, 4·5번 메뉴 변화는 "제안했습니다".
