## 1. 확정 문구 (임의 수정 금지)

### 메인 히어로

```
작은 글씨  제주시 연북로 · 제주 전 지역 출장비 없음
H1        제주에 있는 마케팅 회사, 직접 찾아갑니다
보조       전화 말고, 가게에서 만나 이야기합니다
          음식점·필라테스·뷰티, 매장이 있으면 어디든
```

결정 이유: '제주 마케팅'만 쓰면 "제주를 홍보한다"로도 읽힌다. 회사가 제주에 있고, 전화가 아니라 직접 만난다는 점(육지 업체와의 차이)이 한 번에 보여야 한다. 업종은 음식점만이 아니라 매장이 있는 업종 전체다.

### 섹션 제목·카드

| 위치 | 확정 문구 |
|---|---|
| 메인 — 갈래 카드 A | 다른 대행사에 맡겼는데 관리가 안 되나요? |
| 메인 — 차별점 섹션 | 광고만 하지 않습니다 (→ 7번 참고: 대체 검토 중) |
| 메인·서비스 — 서비스 섹션 제목 | 주요 서비스 |

| 서비스 — 광고 제목 | 광고 결과, 숫자로 보여드립니다 |
| 서비스 — 광고 본문 | 매달 직접 만나서 설명합니다 |
| 서비스 — 컨설팅 제목 | 장사가 안 되는 이유를 찾아드립니다 |
| 서비스 — 컨설팅 본문 | 간판·인테리어 업체도 연결해 드립니다 |
| 실적 숫자 | **60여 곳** + 함께한 제주 가게 |
| 소개 — 강의 섹션 | 매달 사장님들께 마케팅 강의를 합니다 |

| 안심 조건 카드 3개 | 한 달 단위 계약 / 7일 안에 전액 환불 / 위약금 없음 |

| FAQ 섹션 | 자주 묻는 질문 |

## 2. 수정 사례 (현재 → 확정)

| 1차 시안 | 확정 | 무엇이 문제였나 |
|---|---|---|
| 제주에서 직접 만나는 마케팅 | 제주에 있는 마케팅 회사, 직접 찾아갑니다 | 누가 누구를 만나는지 없음. 회사 위치가 약함 |
| 맡겨는 봤는데 관리가 안 되나요? | 다른 대행사에 맡겼는데 관리가 안 되나요? | 누구에게 맡겼는지 빠짐 |
| 손님을 늘리는 일, 이렇게 합니다 | 주요 서비스 | 새로 지어낸 제목. 익숙한 표준 표현이 더 빨리 읽힘 |
| 손님이 멈추는 영상으로 만듭니다 | 인스타·유튜브용 20초 홍보 영상을 만듭니다 | 비유 |
| 걸어놓고 끝내지 않습니다 | 광고 결과, 숫자로 보여드립니다 | 비유. 무엇을 걸었는지 불명확 |
| 매출이 오를 구조를 만듭니다 | 장사가 안 되는 이유를 찾아드립니다 | '구조'가 추상적. 실제로 하는 일과 다름 |
| 제주에서 60여 곳의 매장을 만났습니다 | 60여 곳 + 함께한 제주 가게 | 서술형이라 길고, '만났다'가 모호 |
| 가르치면서 배웁니다 | 매달 사장님들께 마케팅 강의를 합니다 | 말장난 |
| 배우고 현장에서 확인합니다 | 자격증·수상 | 무엇에 대한 섹션인지 알 수 없음 |
| 그만두실 땐 일주일 전에만 | 위약금 없음 + 일주일 전에 알려주세요 | 문장이 끊김 |
| 지금 우리 매장에 뭐가 필요한지, 한 번 들어보세요 | 편하게 물어보세요 | 길고, 누구에게 듣는지 없음 |

### 사용자가 거절한 표현 (다시 쓰지 않음)

| 표현 | 거절 이유 |
|---|---|
| 메뉴와 간판까지 같이 고쳐 드립니다 | 직접 고쳐 주지 않음. 이유를 찾고 외부 업체를 연결할 뿐 |
| 사장님이 카메라 앞에 서지 않아도 됩니다 | 사실과 다름. 출연을 권함 |
| 제주 매장 마케팅 | 아무도 이렇게 검색하거나 말하지 않음 |
| 플레이스 정보 구조 정비, 광고 설정 및 예산 관리, 노출 환경 개선 | 업계 말. 사장님이 이해하기 어려움 |
| 제주 가게 홍보, 직접 찾아가서 합니다 | 제주에 있는 회사라는 느낌이 약함 |

## 3. 고객 언어

### 첫 문의 때 쓴 말

- "광고 홍보 문의드립니다"
- "가게 홍보영상 견적 문의드립니다"
- "안녕하세요, 상담부탁드립니다"
- "혹시 어떤 상품 가능한지 좀 알 수 있을까요?"
- "매출 관리도 같이 해주시나요?"
- "플레이스 상위 노출 작업도 하시나요?"
- "카페 릴스 제작 요청 드리고 싶은데 견적 알 수 있을까요?"

### 문제를 말할 때

- "성실히 매장을 한다고 하는데도 손님이 안 오더라고요"
- "맛있으면 손님이 알아주겠지 하는 마인드였어요"
- "처음에는 믿을 만하게 얘기해요. 근데 한두 달 하다 보면 관리가 안 되고 소홀해지더라고요"
- "다들 돈만 입금해달라고 하니까 그게 싫었어요"
- "숫자 놀이 하는 것 같아서 신뢰가 가지 않음"
- "전화통화로 자세한 매장 이야기를 하는데 한계를 많이 느낌"

### 만족했을 때

- "내 가게처럼 관리해줘서 너무 좋다"
- "한 달에 한 번 직접 만날 수 있다는 게 생각보다 엄청 중요했어요"
- "이 사람이랑 하면 나를 속이지는 않겠구나 싶은 신뢰가 들더라고요"
- "지금 이 시점엔 이게 필요해요라고 먼저 얘기해주는 게 좋았어요"
- "대표님 저희 어제 완전 터졌어요"
- "여름 성수기 만큼.. 웨이팅 120명"

### 망설일 때

- "돈을 투자했는데 매출로 마케팅비가 회수가 되지 않을까봐 두렵다"
- "마진이 적은 음식점에서 큰 비용을 지출하지 못하겠다"
- "마케팅을 처음 해봐서 원하는 결과가 나오지 않을까봐 두렵다"

### 핵심 단어

**홍보, 광고, 영상, 가게, 손님, 매출, 관리, 장사, 견적, 상담**

'마케팅'은 회사명과 업종 설명에만 쓰고, 문장 안에서는 '홍보'나 '광고'를 우선합니다.

### 진행 순서

1. 문의 (카카오톡·전화·상담 신청)
2. 전화 통화 — 가게 상황을 듣고 만날 날을 정함
3. 만나서 계약 — 제주시 사무실이 기본, 상황에 따라 가게로 감
4. 사전 미팅·기획
5. 촬영·납품 (7일 안)
6. 매달 관리 — 월 1회 만남 + 리포트

### 영상 출연

사장님이 나오시는 편이 좋다고 권합니다. 손님은 가게보다 사람을 기억하기 때문입니다. 말을 잘 못해도 괜찮고, 무엇을 할지는 촬영 전에 정리해 드립니다. 어려우면 손이나 뒷모습만 담을 수도 있습니다.
